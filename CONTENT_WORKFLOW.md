# Publishing content

After the Cloudflare setup in `CLOUDFLARE_SETUP.md` is complete, use the **Post Studio** to sign in with the authorized GitHub account and publish blog posts. The **Writeups** page accepts one or more Markdown files after the same account has signed in.

Posts and writeups are stored in Cloudflare D1, so they become public immediately without a Git commit or site rebuild.

The old `content/blog` and `content/writeups` folders are retained as an archive of the previous GitHub Pages workflow. They are no longer used by the live site.
