## Where I'm learning

I picked up the basics of HTML in high school, and I'm now working through web app penetration testing on TryHackMe. It has taught me a lot.

My favourite thing on there is the CTFs — Capture The Flag. You spin up a virtual machine you're allowed to attack, which means you get to practise being an attacker legally, on a system built for it. I run Kali Linux on a Raspberry Pi 5 and work with the same tools professionals use in the field.

TryHackMe also runs a competitive mode called King of the Hill. I haven't tried it yet, but it sounds like a good time. If you decide to sign up, the writeups page has walkthroughs for rooms I've already cleared.
